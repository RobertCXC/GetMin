# 股票行情 Chrome 插件产品需求设计说明

> 版本：v0.1  
> 状态：需求设计阶段  
> 更新时间：2026-09-16

## 1. 产品定位

这是一款运行在 Chrome 浏览器中的轻量级股票行情插件，用于快速查看自选股票行情，并通过分组 Tab 管理不同的股票列表。

产品特点：

- 快速查看自选股票实时行情
- 支持类似同花顺手机 App 的股票分组 Tab 切换
- 支持股票搜索、添加、删除和排序
- 使用东方财富公开行情接口
- 本地保存用户自选数据，无需登录

本产品参考了 [stock-chrome-plugin](https://github.com/g-shifu/stock-chrome-plugin) 的功能形态。参考项目包含实时行情、自选管理、行情详情、提醒、备份恢复等功能，但项目说明中明确提到其代码是 Webpack 打包后的产物，不适合作为二次开发基础。因此本项目建议参考其产品设计，重新实现插件。

## 2. 产品范围

### 2.1 第一版支持范围

- 沪深京 A 股普通股票
- 股票代码和股票名称搜索
- 自选股票管理
- 股票分组 Tab
- 实时价格、涨跌额、涨跌幅
- 股票详情
- 手动刷新和自动刷新
- 本地数据持久化

### 2.2 第一版暂不支持

- 基金、ETF
- 港股、美股
- 股票交易和账户登录
- 资金流向、龙虎榜、财报分析
- 新闻资讯
- 复杂技术指标
- 云端账号同步

## 3. 用户场景

### 3.1 快速查看自选股票

用户点击 Chrome 工具栏中的插件图标，即可查看当前分组下的股票行情。

### 3.2 按投资策略管理股票

用户可以创建不同分组，例如：

- 短线观察
- 中长线
- 重点关注
- 待研究

通过顶部 Tab 快速切换分组，避免所有股票混杂在同一个列表中。

### 3.3 一只股票属于多个分组

同一只股票可以同时加入多个分组。例如贵州茅台可以同时加入“中长线”和“重点关注”。

## 4. 核心功能需求

### 4.1 股票分组 Tab

顶部采用类似同花顺手机端的分组切换方式：

```text
[全部自选] [短线观察] [中长线] [重点关注] [+]
```

功能要求：

- 默认提供“全部自选”系统分组
- 用户可以创建分组
- 用户可以重命名分组
- 用户可以删除分组
- 用户可以调整分组顺序
- 点击 Tab 切换当前股票列表
- 股票可以同时属于多个分组
- 删除分组时，只删除分组关系，不删除股票
- “全部自选”自动汇总所有分组中的股票
- 每个分组显示股票数量
- 当前选中的分组在插件重新打开后保持不变

建议限制：

- 分组数量建议不超过 20 个
- 单个分组至少支持 100 只股票
- 股票顺序可单独保存到每个分组中

### 4.2 股票搜索与添加

搜索框支持：

- 股票代码搜索，例如 `600519`
- 股票名称搜索，例如 `贵州茅台`
- 后续可增加拼音搜索
- 输入后进行防抖搜索
- 展示股票名称、代码和市场
- 选择股票后可加入一个或多个分组
- 已添加的股票显示“已添加”状态

股票识别不能只依赖股票代码前缀，而应保存东方财富返回的完整 `secid`，例如：

```text
1.600519
0.000001
```

这样可以避免不同市场股票代码判断错误。

### 4.3 行情列表

每只股票显示：

- 股票名称
- 股票代码
- 最新价
- 涨跌额
- 涨跌幅
- 更新时间
- 数据状态

示例：

```text
贵州茅台
600519       1420.00
             +12.50  +0.89%
```

显示规则：

- 上涨使用红色
- 下跌使用绿色
- 平盘使用灰色
- 价格字段为空时显示 `--`
- 接口异常时保留最近一次行情，并显示“数据已过期”
- 当前分组为空时显示空状态和“添加股票”按钮

### 4.4 股票详情

点击股票后进入详情视图，第一版显示：

- 股票名称和代码
- 最新价
- 涨跌额和涨跌幅
- 今开
- 最高
- 最低
- 昨收
- 成交量
- 成交额
- 换手率
- 市盈率
- 市净率
- 总市值
- 流通市值
- 行情更新时间

详情页面提供：

- 返回列表
- 打开东方财富网页
- 从当前分组移除
- 加入其他分组

详情页同时提供分时、日 K、周 K 三种走势图，按需加载并使用前复权数据；实时指标作为“行情摘要”保留在走势图下方。

### 4.5 股票排序

第一版默认使用用户手动排序。

后续可以支持：

- 按涨跌幅排序
- 按涨跌额排序
- 按最新价排序
- 按股票代码排序
- 升序或降序切换

## 5. 界面设计

### 5.1 弹窗布局

建议插件弹窗宽度为 400～480 像素，满足快速查看需求。

```text
┌─────────────────────────────┐
│ 股票行情       [刷新] [设置] │
├─────────────────────────────┤
│ 全部自选  短线  中长线  [+]   │
├─────────────────────────────┤
│ 沪深股市 · 更新于 10:32:15    │
├─────────────────────────────┤
│ 贵州茅台       1420.00       │

├─────────────────────────────┤
│ 平安银行       11.23         │
│ 000001         -0.44%        │
├─────────────────────────────┤
│              [添加股票]       │

```

### 5.2 分组管理交互

- 点击 `+` 创建分组
- 点击分组旁的管理按钮进行重命名、删除和排序
- 支持拖拽调整分组顺序
- 删除分组时弹出确认提示
- 删除分组时明确提示“只删除分组，不删除股票”

### 5.3 行情列表交互

- 点击股票进入详情
- 右键或更多菜单显示操作项
- 支持从当前分组移除股票
- 支持将股票加入其他分组
- 支持拖拽调整股票顺序

## 6. 东方财富接口设计

建议统一封装为 `EastmoneyAdapter`，界面层不直接依赖东方财富原始字段。

### 6.1 接口规划

| 用途 | 接口 |
| --- | --- |
| 股票列表和搜索 | `push2.eastmoney.com/api/qt/clist/get` |
| 批量实时行情 | `push2.eastmoney.com/api/qt/ulist.np/get` |
| 单只股票详情 | `push2.eastmoney.com/api/qt/stock/get` |
| K 线数据 | `push2his.eastmoney.com/api/qt/stock/kline/get` |

东方财富接口返回大量 `f` 编号字段，例如代码、名称、最新价、涨跌幅、成交量等。具体字段转换应集中在数据适配层，并通过固定响应样本进行测试。

字段参考：[Eastmoney API 字段说明](https://github.com/WangYang-Rex/eastmoney-data-sdk/blob/main/docs/API_FIELDS.md)

### 6.2 刷新策略

- 默认每 10 秒刷新一次
- 只刷新当前打开的分组
- 多只股票使用批量接口，避免一只股票请求一次
- 切换分组时优先使用缓存
- 手动刷新时绕过缓存
- 插件关闭后停止轮询
- 非交易时间显示最近行情和“休市”状态
- 接口失败时自动重试并显示错误状态
- 不把实时行情长期写入本地存储

由于这些接口属于网页侧公开接口，设计上需要考虑字段变化、访问限制和接口不可用情况，因此需要保留缓存、重试和错误提示机制。

## 7. 数据结构设计

```ts
type Stock = {
  id: string;          // Eastmoney secid，例如 1.600519
  code: string;        // 600519
  name: string;        // 贵州茅台
  market: string;      // SH、SZ、BJ
};

type StockGroup = {
  id: string;
  name: string;
  stockIds: string[];
  order: number;
};

type AppSettings = {
  refreshInterval: number;
  colorMode: "china" | "western";
  theme: "light" | "dark" | "system";
};
```

### 7.1 本地保存内容

- 分组信息
- 股票信息
- 股票在各分组中的顺序
- 当前选中的分组
- 刷新间隔和界面设置

行情缓存只放在运行时内存或 `chrome.storage.session` 中，不作为用户数据永久保存。

## 8. 技术方案

推荐技术栈：

- Chrome Extension Manifest V3
- React
- TypeScript
- Vite
- pnpm
- CSS Modules 或 Tailwind CSS
- 原生 Chrome Extension API

建议项目结构：

```text
popup/
  股票列表和分组 Tab

options/
  设置、数据导入导出

background/
  service worker
  东方财富接口请求
  消息转发
  后续行情提醒

shared/
  类型定义
  数据适配器
  存储服务
```

Manifest V3 使用 Service Worker 作为后台环境，并且不能依赖远程加载的 JavaScript，因此所有代码应随插件一起打包。

参考：[Chrome Manifest V3](https://developer.chrome.com/docs/extensions/develop/migrate/what-is-mv3)

第一版建议只申请以下权限：

```json
{
  "permissions": ["storage"],
  "host_permissions": [
    "https://*.eastmoney.com/*"
  ]
}
```

第一版不需要申请 `tabs`、`scripting` 等额外权限。Chrome 官方也建议尽可能缩小扩展权限范围。

参考：[Chrome 权限声明](https://developer.chrome.com/docs/extensions/develop/concepts/declare-permissions)

## 10. 验收标准

MVP 完成后应满足：

1. 安装插件后可以正常打开股票行情弹窗。
2. 可以通过代码或名称搜索 A 股股票。
3. 可以将股票加入一个或多个分组。
4. 可以创建、修改、删除和切换分组。
5. 分组和股票关系在关闭插件后仍然保留。
6. 切换 Tab 后显示对应分组的股票。
7. 股票行情可以批量刷新。
8. 东方财富接口异常时不会导致插件白屏。
9. 行情字段为空或过期时有明确提示。
10. 不包含基金、ETF 和交易功能。

## 11. 实施约定

- 第一阶段先实现 MVP，不提前加入基金功能。
- 东方财富请求统一放在数据适配层中。
- 界面层只使用标准化后的股票和行情对象。
- 所有 Node.js 依赖和构建命令统一使用 `pnpm`。
- 不使用 `npm` 作为项目包管理器。
- 本文档确认后，再开始创建 Chrome 插件项目代码。
