# 股票行情 Chrome 插件

这是根据 `docs/股票行情Chrome插件-产品需求设计说明.md` 实现的第一版 MVP，使用 Manifest V3、React、TypeScript、Vite 和 pnpm。

## 当前功能

- 沪深京 A 股代码/名称搜索，使用东方财富返回的完整 `secid`。
- “全部自选”与自定义分组 Tab；同一只股票可加入多个分组。
- 分组创建、重命名、删除、拖拽排序。
- 当前分组股票拖拽排序。
- 批量行情刷新：最新价、涨跌额、涨跌幅、状态和更新时间。
- 股票详情：分时、日 K、周 K 走势图，并保留开高低、昨收、成交量、成交额、换手率、估值和市值字段。
- 手动刷新、默认 10 秒自动刷新、运行时缓存和接口失败后的过期提示。
- Chrome 本地存储保存分组、股票关系、当前 Tab 和显示设置。
- 设置页支持刷新间隔、红涨绿跌/绿涨红跌和主题切换。

## 开发与加载

```powershell
pnpm install
pnpm typecheck
pnpm build
```

构建完成后，在 Chrome 打开 `chrome://extensions`，开启“开发者模式”，选择“加载已解压的扩展程序”，目录选择 `dist`。

行情请求由 `src/background/service-worker.ts` 统一转发到 `src/shared/eastmoney.ts`，弹窗界面不直接依赖东方财富原始字段。东方财富接口属于公开网页接口，字段或访问策略变化时，插件会显示错误并保留运行时最近行情。

## 第一版边界

当前不包含基金、ETF、港股、美股、交易、登录、新闻、资金流向和复杂技术指标。
